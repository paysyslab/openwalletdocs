# Customer Posting


The **Customer Posting** module enables authorized users to search customers and perform secure debit or credit entries on their accounts.

![Customer Posting](/img/customer-posting.png)

---

## Customer Search

You can search a customer using any of the following identifiers:

- **CNIC**
- **Mobile Number**
- **Account Number**
- **IBAN**

Once a record is found, the system displays key customer details:

- Customer CNIC  
- Customer Name  
- Registered Mobile Number  
- Account Number  
- IBAN  

This ensures every posting is made to the correct customer account.

---

## Transaction Posting

After selecting a customer, you can initiate a manual transaction posting.  
The module supports **both Debit and Credit** entries.

### **Fields Included**
- **Posting Date**  
- **Purpose** *(e.g., cash deposit, adjustment, reversal, correction)*  
- **Reference Number** *(optional)*  
- **Transaction Type** *(Debit / Credit)*  
- **Transaction Nature** *(Cash, Adjustment, Internal Transfer, etc.)*  
- **Amount**  
- **Narration** *(description for audit & history)*  

---

## What This Module Enables

- Correct customer balances  
- Adjust or fix system entries  
- Post manual credits or debits  
- Handle exception cases  
- Maintain full posting audit logs  

---

## Notes

- All actions are saved with complete **audit trails**.  
- Only users with the right privileges can perform postings.  
- Always verify customer identity before posting.
